# 全景知识地图样品

采用用户指定的 Anthropic frontend-design skill，延续 Apple 风格的白、浅灰与系统字体。以结构和动态讲解替代大段阅读作为入口；样品为独立 `/map` 路由，现有首页保留。

## 构图

```
报告全景 / 分支 / 案例                         搜索 / 播放导览
数据与决策 ─ 六个案例  ╲           ╱ 知识与培训 ─ 四个案例
                        AI如何落地 ─ 流程自动化 ─ 五个案例
销售与内容 ─ 五个案例  ╱           ╲ 组织与协作 ─ 四个案例
缩略地图                当前理解 / 图例             缩放 / 全景
```

色彩：背景 #f7f8fa；节点白 #fff；文字 #1d1d1f；数据蓝 #3478ce；知识青 #228782；流程紫 #7862c5；销售金 #b17835；协作玫瑰 #aa6686。分支色传达分类，同一主题从概览到细节保持一致。节点字号 16–21px，控件 12–14px，按摄像机缩放；正文解释控制在一段，原文按需打开。

首次直接展示报告结构。桌面显示24个案例，手机先显示五类问题，点击进入分支再显示案例。分类是本站整理，并非报告作者的统一分类。进入案例后只出现短语节点：业务痛点、三个实施步骤、实际反馈与必须保留的边界。

动态：指针定位缩放、拖拽和平移、双指捏合、平滑定位、缩略图定位、选中路径高亮。讲解模式每次突出一个因果关系，可暂停、前后切换、退出。减少动效偏好禁用过渡和流动线条。

样品主场景是可操作的关系图；不添加装饰性的3D旋转，不增加无依据的因果或收益。所有24个案例均可展开为结构。

## 验证

通过生产构建与8项检查，其中地图检查覆盖指针定位缩放、缩放上限、负坐标适配、分支不重叠和连线端点。浏览器已验证桌面1460×920与手机390×844：分支展开与折叠、搜索跳转、节点说明、实际拖动与双指缩放、减少动效、导览暂停和自动完成，以及案例深链接刷新。导览在桌面完整保留案例结构，手机放大当前讲解节点；底部讲解面板避让当前节点。

访问 `#/map`，点击「播放导览」开始8步示范；任何时候可暂停、跳转或退出。选中案例会生成 `#/map?case=编号`，可复制分享。地图支持 `+`、`-` 缩放，方向键移动，`Home` 适应画布，`Esc` 返回。讲解中用左右键切换、空格暂停。
