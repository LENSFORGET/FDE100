# FDE100 导读设计

采用用户指定的 Anthropic frontend-design skill（2026-09-12 读取），以其先定方向、再构建和截图自评的流程为准。参考 https://www.apple.com/hk/ 的阅读层级、留白、安静导航和明确操作，不使用 Apple 标志或产品素材。

## Tokens
白 #ffffff；浅灰 #f5f5f7；正文 #1d1d1f；次要文字 #6e6e73；操作蓝 #0071e3；分隔 #d2d2d7。
字体使用系统 -apple-system / BlinkMacSystemFont / PingFang SC，主标题 72/1.12，区域标题 40/1.2，正文 17/1.8，阅读区正文 18/1.95。正文限宽 720px。系统字体贴合 Apple 风格，中文不依赖外部字体请求。

## Layout
首页集中介绍读者收益；案例发现和长文阅读独立，避免长首页压过真实内容。首页用报告的真实封面作为视觉锚点，内容均为原生 HTML。全局导航窄而安静，阅读页左侧目录、中间正文，工具按需出现。

```
导航：FDE100 导读 | 报告导读  案例库  我的阅读 | 原报告
首页：居中主标题 / 两个阅读入口 / 实际报告封面与内容预览
      三条阅读路线 / 精选案例 / 来源说明
案例库：标题 / 搜索 / 业务问题与行业筛选 / 案例 / 比较栏
阅读：目录 | 一句话 / 问题 / 方案 / 结果及边界 / 讲解提纲 / 原文
```

自评修订：不采用所有功能挤在首屏的仪表盘；不把24个案例都当作已经成熟的成功方案。案例编号仅用于报告定位。首页突出从具体问题理解 AI，避免虚构100篇或汇总不同比较口径的收益。

交互：搜索、行业与问题筛选、深链接、收藏、已读、双案例比较、讲解提纲下载、阅读笔记。无后端；状态仅存当前浏览器。原文带 PDF 物理页与印刷页定位，读者可展开访谈全文并跳到 PDF 看图表。
