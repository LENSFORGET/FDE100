# FDE100 首次访问与阅读设计

使用用户指定的 [Anthropic frontend-design skill](https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md)，2026-09-12 再次读取。当前参考 [Apple 首页](https://www.apple.com/) 的大尺度内容展示、清楚的操作层级、系统字体和克制的材质。本站视觉主体是可操作的报告结构，不使用 Apple 标志、产品图片或宣传文案。

## 本轮目标

第一次进入就知道：这是 Datawhale 报告的独立互动导读，可以看结构、读精华、找案例、准备分享。四条入口与 GitHub 仓库、引用来源在首屏出现。已有地图成为主要入口；案例先展示重点，再由用户选择完整解读、讲解提纲和访谈原文。

## 视觉约定

- 白 #ffffff：阅读面；银灰 #f5f5f7：分区与结构演示的底面。
- 墨色 #1d1d1f：标题与重点；石灰 #626269：次要解释。
- 操作蓝 #0071e3：主要动作；柔灰 #d2d2d7：必要分隔。
- 使用系统 SF / PingFang 字体，首页标题 64px、分区标题 42px、正文 17px，阅读正文 18px。中文正文限宽约38字，关键词用真实 strong 标签。
- 页面按内容价值区分大小；标题、重点、依据和操作各有位置。白与银灰分区，少量细边与自然阴影构成层次；动效回应切换与展开，尊重减少动效偏好。

## 设计自评与修订

旧首页的报告封面和长介绍占用了最重要的位置，地图、讲解与对比的价值要探索后才发现。本轮把原封面移到来源区；首屏以真实案例的短结构演示本站的用途。四条用户路径使用平面的图标导航，不做四张重复的大卡片。案例卡片优先说明可学到的方法，结果数字连同适用边界呈现。

精华是本站对受访者 Q4 项目反馈、Q5 挑战、Q6 经验的整理，选择依据是可迁移、可行动、有来源。每篇新总结保存原文定位与对应短语，区分受访者经验和本站建议。保留原报告24篇的顺序、原文、编号及官网映射；不虚构官方排名或读者评分。

构建后检查桌面和手机截图；验证首屏入口、来源与仓库链接、重点与原文切换、来源定位、搜索筛选、地图导览、收藏笔记和导出流程。
